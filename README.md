# youtube-agent

Výroba fakticky podložených YouTube videí (CZ, později DE). Agent `/viral-video <osobnost>` je v
`.claude/skills/viral-video/SKILL.md`, nástroje v `pipeline/` (viz `pipeline/README.md`).

- Mac: prostředí v `~/youtube-agent-env` (`pipeline/README_SETUP.md`).
- Cloud (claude.ai projekt): `bash setup/cloud_setup.sh`, projekty v `/mnt/project-files/youtube/projects/`.
- Pouze nástroje zdarma; nic placeného se neaktivuje bez výslovného souhlasu.
